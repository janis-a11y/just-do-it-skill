# just-do-it

![Shia LaBeouf — Just Do It](assets/shia-just-do-it.jpg)

A skill for coding agents. The whole skill is:

**Just do it.**

## Install

Copy the `SKILL.md` file into your agent's skills folder, e.g.:

```sh
# Claude Code / generic Agent Skills layout
mkdir -p .agents/skills/just-do-it
cp SKILL.md .agents/skills/just-do-it/SKILL.md
```

Or clone this repo and point your agent at it. No dependencies, no scripts, no config.

## Use

Whenever the agent can't do something, hits a limitation, or is about to say it can't be done — it takes on Shia's persona and just does the task instead.
